# Code of Conduct: Dos and Don'ts

- **DO**: Lock workstations (Windows+L), report security incidents/lost assets to SOC (+91-800-555-0199) within 30 minutes, and use Corporate VPN for all sensitive data.
- **DON'T**: Install unapproved/pirated software, connect to public/unsecured Wi-Fi for work, or share corporate credentials/MFA codes with anyone.
